# GitNexus team demo

โปรเจกต์ร้านค้าจำลองสำหรับเปรียบเทียบ AI สำรวจโค้ดตามปกติ กับ AI ที่ใช้ GitNexus เพิ่มเติม
โค้ดตั้งใจให้เล็กและตรวจสอบได้ ไม่ใช่ benchmark ตัวแทนโปรเจกต์ใหญ่ และไม่รับประกันว่า GitNexus จะชนะ

## เริ่มต้น

ต้องมี Node.js 22 ขึ้นไป ไม่ต้องติดตั้ง dependencies ของแอป

```sh
npm test
npm run demo
```

## โจทย์

ใช้ข้อความใน `PROMPT.md` เหมือนกันทั้งสองรอบ อย่าให้ AI เห็นคำตอบจากรอบก่อน
วิเคราะห์อย่างเดียว ไม่แก้โค้ด แล้วส่งคำตอบพร้อมหลักฐาน

## เตรียมการเปรียบเทียบ

1. commit และ push baseline นี้ก่อน จากนั้น clone commit เดียวกันเป็น A และ B นอกโฟลเดอร์ที่แชตอีกฝั่งเข้าถึง
2. A ใช้เครื่องมืออ่านไฟล์/ค้นหา/รันทดสอบตามปกติ ปิด GitNexus integration และ hooks
3. B ใช้เครื่องมือแบบเดียวกันและเพิ่ม GitNexus ติดตั้งและสร้างดัชนีเฉพาะ B ตาม README ของ GitNexus
4. บันทึกเวอร์ชัน GitNexus และ Node, commit SHA, โมเดล, reasoning, tool permissions และเวลาสร้างดัชนี
5. เปิดแชตใหม่ทุกครั้ง ใช้เวลาไม่เกิน 5 นาทีต่อรอบ สลับลำดับ A/B และทำอย่างน้อยแบบละ 3 รอบ
6. บันทึกเวลาจนได้คำตอบ และตรวจคำตอบกับเฉลยที่ผู้จัดเก็บไว้นอก repo นี้

ตัวอย่างคำสั่งสำหรับ B (ตรวจสอบเอกสาร upstream ก่อนใช้งาน):

```sh
npx gitnexus@<VERSION> analyze
```

แทน `<VERSION>` ด้วยเวอร์ชันเดียวกันที่เลือกใช้ตลอดการทดลอง เชื่อม MCP ตามเครื่องมือ AI ที่ใช้
`analyze` อาจสร้างไฟล์บริบทหรือ skills เพิ่มเติม ให้เก็บสิ่งเหล่านี้เฉพาะ B
หากตั้งค่า MCP แบบ global ให้แยก profile เพื่อไม่ให้ A เข้าถึง B
การทดลองนี้วัดแพ็กเกจการใช้งาน GitNexus รวมบริบทที่สร้างขึ้น ไม่ได้แยกผลของกราฟอย่างเดียว

## ขอบเขตการวัด

นับเฉพาะ production callers/consumers ภายใน `src/` แยก direct กับ indirect
ไม่คิด scripts, tests, re-export-only module เป็นรายการผู้เรียกใช้ที่ต้องให้คะแนน
ความสัมพันธ์ในกราฟไม่เท่ากับยืนยันว่าเกิด bug ต้องตรวจพฤติกรรมจาก source และ tests
